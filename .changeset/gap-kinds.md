A "never documented" finding says what kind of member is missing (`LivelyServer` has a `port` getter this page never documents) and, when the same name appears on the page as an option key, says that it is not the member. "Never mentioned" reads "never documented" throughout. On Drift 1.16.13, a member used inside a code comment counts as documented.
